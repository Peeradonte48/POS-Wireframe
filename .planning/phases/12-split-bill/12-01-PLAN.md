  <action>
Create `src/stores/bill.store.ts` as a new Zustand persist store. Follow the exact same `create<T>()(persist(...))` pattern as `order.store.ts` with `{ name: 'bill-store' }`.

**Types to export:**

```typescript
export type SplitMode = 'equal' | 'per-seat'

export interface SeatAssignment {
  lineId: string        // references OrderLineItem.lineId
  seatIndex: number     // 0-based seat index
  assignedQty: number   // partial qty assigned to this seat (for qty>1 items)
}

export interface SeatPaymentRecord {
  method: 'Cash' | 'QR PromptPay' | 'Card'
  paidAt: number        // Date.now()
  amount: number        // satang-rounded seat total
}

export interface BillSplit {
  tableId: string
  mode: SplitMode
  seatCount: number
  equalAmounts: number[]   // for equal mode: pre-computed [seat0, seat1, ...], length === seatCount
  assignments: SeatAssignment[]  // for per-seat mode
  payments: Record<number, SeatPaymentRecord>  // keyed by seatIndex; undefined = unpaid
}
```

**Actions to implement:**

- `initEqualSplit(tableId, grandTotal, seatCount)` — compute `equalAmounts` using floor+remainder-on-last (integer math), set `mode: 'equal'`, `payments: {}`, `assignments: []`. Algorithm:
  ```typescript
  const base = Math.floor(grandTotal / seatCount)
  const remainder = grandTotal - base * seatCount
  const equalAmounts = Array.from({ length: seatCount }, (_, i) =>
    i === seatCount - 1 ? base + remainder : base
  )
  ```

- `initPerSeatSplit(tableId, seatCount)` — set `mode: 'per-seat'`, `equalAmounts: []`, `assignments: []`, `payments: {}`; use `useTableStore.getState().tables[tableId]?.guestCount ?? seatCount` as the canonical seatCount (pass in from caller)

- `assignItem(tableId, lineId, seatIndex, qty)` — upsert a `SeatAssignment` (if lineId already exists for that seatIndex, replace assignedQty; if lineId exists for a different seatIndex, remove old entry first, then add new)

- `unassignItem(tableId, lineId)` — remove all `SeatAssignment` entries matching lineId for the tableId

- `recordPayment(tableId, seatIndex, record)` — add to `payments[seatIndex]`; do NOT trigger markCleaning from here (that is the UI's responsibility)

- `cancelSplit(tableId)` — delete `splits[tableId]` from the store entirely (use `const { [tableId]: _, ...rest } = state.splits` pattern to avoid mutation)

- `getSplit(tableId)` — returns `BillSplit | undefined` from `state.splits[tableId]`

**Critical rules:**
- Do NOT import from order.store — seat assignments reference lineId as a string key only
- Mark the file `'use client'` at top (matches all other stores)
- No default export — only named `useBillStore`
