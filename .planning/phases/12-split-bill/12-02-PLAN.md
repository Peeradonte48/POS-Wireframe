  <name>Task 2: Create SplitSheet.tsx — full split bottom sheet with all internal view states</name>

  <action>
Create `src/components/payment/SplitSheet.tsx`. This is the main component for the entire split flow.

**Props interface:**
```typescript
interface SplitSheetProps {
  open: boolean
  onClose: () => void
  tableId: string
  grandTotal: number          // full bill grand total (post-discount)
  billItems: OrderLineItem[]  // non-voided items from order (for per-seat assignment)
}
```

**Internal view state machine** (local `useState`):
```
'mode-select'     → initial: choose Equal Split or Per Seat
'equal-config'    → enter guest count N (default: guestCount from table.store)
'equal-seats'     → N seat cards, each tappable to open SeatPaymentPanel
'per-seat-assign' → unassigned bucket + seat sections, item tap → seat picker
'per-seat-pay'    → all items assigned; seat cards with Pay buttons
```

**Mode selector view ('mode-select'):**
- Two large tappable cards: "Equal Split" and "Per Seat"
- Subtext on each: Equal → "Divide total equally among guests"; Per Seat → "Assign each item to a seat"
- Tapping Equal → sets view to 'equal-config'
- Tapping Per Seat → calls `useBillStore.getState().initPerSeatSplit(tableId, guestCount)` then sets view to 'per-seat-assign'
- Cancel button at bottom calls `cancelSplit(tableId)` + shows `toast('Split cancelled')` + calls `onClose()`

**Equal config view ('equal-config'):**
- Numeric input for seat count N — default from `useTableStore.getState().tables[tableId]?.guestCount ?? 2`
- Min 2, max 20
- "Confirm" button: calls `initEqualSplit(tableId, grandTotal, N)` + sets view to 'equal-seats'
- Back button → sets view to 'mode-select'

**Equal seats view ('equal-seats'):**
- Read `split.equalAmounts` and `split.payments` from `useBillStore`
- Render one card per seat (0 to seatCount-1)
- Each unpaid seat card shows: "Seat {i+1}", "฿{amount.toLocaleString()}", and "Pay" button
- Tapping "Pay" expands `SeatPaymentPanel` inline for that seat (collapse others via `activeSeatIndex` local state)
- `onPaid` callback: calls `recordPayment(tableId, seatIndex, record)`, collapses panel, checks if all seats paid
- If all seats paid: call `useTableStore.getState().markCleaning(tableId)`, call `cancelSplit(tableId)` (clears stale state), call `onClose()`, then call the `onAllPaid()` callback (for navigation — passed as prop, see below)
- Settled seat cards: green `Settled` badge + payment method label, `opacity-60` on the card, no Pay button

**Per-seat assign view ('per-seat-assign'):**
- Read `split.assignments` and `split.seatCount` from `useBillStore`
- Unassigned bucket (top section, labeled "Unassigned"): list of items where qty is not fully assigned across all seats
  - For each item: show name, qty, unit price; compute `assignedTotal` = sum of assignments for this lineId; `unassignedQty = item.quantity - assignedTotal`
  - Items with `unassignedQty > 0` appear here
- Tapping an unassigned item → open seat picker (local state: `assigningLineId`, `assigningLineQty`)
- Seat picker: horizontal row of numbered seat buttons (Seat 1, Seat 2, ..., Seat N)
  - If `unassignedQty > 1`: show inline stepper `[−] {qty} [+]` below the seat buttons (default qty = 1, max = unassignedQty)
  - Tapping a seat button with qty: calls `assignItem(tableId, lineId, seatIndex, qty)`, closes picker
- Each seat section (Seat 1..N): lists items assigned to it with their quantities and subtotals
- Already-assigned items can be tapped to re-assign (tap → seat picker appears, calling `unassignItem` then `assignItem`)
- "Continue to Pay" button — enabled only when unassigned bucket is empty (all items fully distributed) → sets view to 'per-seat-pay'
- Back button → sets view to 'mode-select'

**Per-seat pay view ('per-seat-pay'):**
- Same as equal-seats card layout but amounts are derived from per-seat computation:
  ```typescript
  const seatSubtotal = split.assignments
    .filter(a => a.seatIndex === i)
    .reduce((sum, a) => sum + a.assignedQty * billItems.find(it => it.lineId === a.lineId)!.basePrice, 0)
  const seatVat = Math.round(seatSubtotal * 0.07)
  const seatTotal = seatSubtotal + seatVat
  ```
- Per-seat totals shown per seat: subtotal + VAT + total (mini-receipt per seat)
- Payment and settled behavior identical to equal-seats view
