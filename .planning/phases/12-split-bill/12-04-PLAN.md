import { ScissorsLinear } from 'solar-icon-set'

Add these imports:

Update `<TotalsSection>` — add the `onSplitBill` prop:

Mount `<SplitSheet>` in the payment view JSX — place it just before the closing `</>` of the payment view return (after the sticky bottom bar div):

  open={splitSheetOpen}
