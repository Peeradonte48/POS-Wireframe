  <name>Task 1: Extend bill.store.ts with merges map and actions</name>
  <files>src/stores/bill.store.ts</files>
  <action>
Add `merges: Record<string, string>` to the BillStore interface (key = secondaryTableId, value = primaryTableId). Initialize to `{}` in the store body. Add five new actions to the interface and implementation:

1. `initMerge(primaryTableId: string, secondaryTableIds: string[]): void`
   Uses `set((state) => ({ merges: { ...state.merges, ...Object.fromEntries(secondaryTableIds.map((id) => [id, primaryTableId])) } }))`.
   A table already listed as a secondary for a different primary must NOT be added (guard: filter out ids already in state.merges before inserting — one primary per secondary constraint).

2. `dissolveAll(primaryTableId: string): void`
   Removes all entries where the value equals primaryTableId:
   `set((state) => ({ merges: Object.fromEntries(Object.entries(state.merges).filter(([, v]) => v !== primaryTableId)) }))`.

3. `isMergedSecondary(tableId: string): boolean`
   Returns `tableId in get().merges` — O(1) map lookup.

4. `getPrimaryTable(tableId: string): string | undefined`
   Returns `get().merges[tableId]`.

5. `getMergedSecondaries(primaryTableId: string): string[]`
   Returns `Object.keys(get().merges).filter((k) => get().merges[k] === primaryTableId)`.

The `merges` field must be included in the persist name 'bill-store' — it is already covered since the whole store is persisted; no config change needed.

Do NOT change any existing split actions or interfaces.
