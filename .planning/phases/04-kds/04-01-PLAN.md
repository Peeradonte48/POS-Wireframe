- Export interface `RecalledTicket`: ticket: KdsTicket, recalledAt: number
- Define `KdsStore` interface with:
  - tickets: Record&lt;string, KdsTicket&gt; (keyed by ticketId)
  - recallTray: RecalledTicket[] (cap at 5 entries — silently drop oldest when exceeded)
  - demoActive: boolean
  - Actions: addTicket(tableId, tableLabel), bumpTicket(ticketId), checkItem(ticketId, lineId), uncheckItem(ticketId, lineId), recallTicket(ticketId), clearRecall(ticketId), toggleDemoActive()
- Implement addTicket: creates KdsTicket with stage 'New', addedAt: Date.now(), checkedItems: new Set()
- Implement bumpTicket: New → InProgress, InProgress → Ready, Ready → removes ticket from tickets and pushes snapshot to recallTray (capped at 5 — shift oldest if over limit)
- Implement checkItem: creates new Set from existing checkedItems and adds lineId (NEVER mutate Set in place — Zustand shallow equality won't detect mutation)
- Implement uncheckItem: creates new Set and deletes lineId
- Implement recallTicket: finds ticket in recallTray by ticketId, removes from tray, restores to tickets Record with stage 'Ready'
- Implement clearRecall: removes ticket from recallTray only
- Implement toggleDemoActive: flips demoActive boolean
- Export useKdsStore = create&lt;KdsStore&gt;(...)
