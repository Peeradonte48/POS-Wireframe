Update src/app/(kds)/kds/page.tsx:
- Import buildMockDemoTicket, getDemoOrderItems from '@/lib/mock-data/kds-demo'
- Import addTicket action from useKdsStore (already imported)
- Add demo injection useEffect — use setTimeout re-schedule pattern (per research recommendation; better randomness than setInterval):
  ```typescript
  useEffect(() => {
    if (!demoActive) return

    let timeoutId: ReturnType&lt;typeof setTimeout&gt;

    function scheduleNext() {
      const delay = 8000 + Math.random() * 4000  // 8–12 seconds
      timeoutId = setTimeout(() => {
        const mockTicket = buildMockDemoTicket()
        // Inject directly into kds.store tickets (NOT into order.store — avoids polluting floor map)
        // Use addTicket with a flag approach: call useKdsStore.getState().tickets to check
        // then call a direct injectDemoTicket action if it exists, or addTicket + then patch
        // Simplest approach: call addTicket(mockTicket.tableId, mockTicket.tableLabel)
        // BUT addTicket creates a new ticket with addedAt=now, stage=New — that's exactly what we need
        // The mock items are accessible via getDemoOrderItems — KdsBoard must also handle demo tickets
        // whose tableId is NOT in order.store. Add a guard in KdsBoard: when deriving orderItems for
        // KdsTicketCard, also check getDemoOrderItems(ticket) as fallback if order store has nothing.
        addTicket(mockTicket.tableId, mockTicket.tableLabel)
        scheduleNext()
      }, delay)
    }

    scheduleNext()
    return () => clearTimeout(timeoutId)
  }, [demoActive, addTicket])
  ```
- Note: addTicket must be destructured from useKdsStore and included in useEffect deps
