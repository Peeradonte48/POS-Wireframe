         - Render options as a row of toggle buttons. Each button: `variant={selected ? 'default' : 'outline'}` + `size="sm"`. On click, set the corresponding state (selectedBroth or selectedFirmness based on group.id).
       - For `group.type === 'multi'` (toppings):

       - On tap button i: set `spiceLevel` to i
       - Ref: `<div ref={(el) => { groupRefs.current['spice'] = el }}>` wrapping this section

    5. **Special Request** (always shown, optional):
       - `<textarea>` or `<Input>` with label "Special Request (optional)"
       - Blur-update pattern: local state `specialRequest`, write to component state on change (not blur — this is within-sheet state, not store state)
       - `placeholder="e.g. no onion, extra firm noodles"`
       - Max length 100 characters

    - Always active (never disabled)
    - Label: "Add to Order" when `editingLineId === null`, "Update Order" when editing

        quantity: quantity,

      }
