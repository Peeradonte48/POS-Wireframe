    Props:
    ```typescript
    interface TicketPanelProps {
    ```

    Read from stores:
    ```typescript
    const order = useOrderStore((s) => s.orders[tableId])   // select only this table

    ```

    State:
    - `voidingLineId: string | null` — which lineId is pending void authorization (controls ManagerPinModal open)

    **Compute from order:**
    - `allItems`: flatten all rounds → items into a single array (all rounds for display)
    - `hasUnsentItems`: any item with status === 'unsent' exists across all rounds
    - `hasSentItems`: any item with status === 'sent' || 'voided' exists
    - `runningTotal`: sum of `(item.basePrice * item.quantity)` for non-voided items + sum of `(topping.priceAdj * item.quantity)` for selected toppings — use a helper to compute total across all items

    **Layout:**
    - Outer: `flex flex-col h-full`
    - Header: `px-4 py-3 border-b` — if hasSentItems and !hasUnsentItems, show `<Button variant="outline" size="sm" className="w-full" onClick={handleAddItems}>Add Items</Button>`. If no items at all: show `<p className="text-sm text-muted-foreground">No items yet</p>`.
    - Body: `flex-1 overflow-y-auto` — renders all rounds with their items. Group by round with a subtle round divider if there are multiple rounds:
      - If only one round, no divider needed
      - If multiple rounds, show `<div className="text-xs text-muted-foreground px-4 py-1 bg-muted/50">Round {i + 1} {round.sentAt ? '· Sent' : '· Pending'}</div>` before each round's items
      - Render each item as `<TicketLineItem>` with correct callbacks
    - Footer: `h-16 border-t flex items-center justify-between px-4 gap-2`
      - Left: `฿{runningTotal.toFixed(0)}` in `text-sm font-semibold`
      - Right: `<Button onClick={handleSend} disabled={!hasUnsentItems} className="h-10 px-4">Send to Kitchen</Button>`

    **handleSend:**
    1. Call `useOrderStore.getState().sendRound(tableId)`
    2. Call `updateTable(tableId, { orderStage: 'Ordered' })` (ORDER-07)
    3. Call `toast('Order sent to kitchen')` — import `toast` from `sonner`; wrap the app's root with `<Toaster>` (see OrderPage wiring below)
    4. State after send: `hasUnsentItems` will be false → Send button disables, Add Items button appears

    **handleAddItems:** No action needed in store — the next item tap will trigger ModifierSheet, which calls addItem, which creates a new round on-demand. Just visually toggle back to browsing mode. This is already handled by the unsent state.

    **void flow:**
    - `onVoidTap`: set `voidingLineId` to the lineId → ManagerPinModal opens
    - ManagerPinModal `onAuthorize`: call `useOrderStore.getState().voidItem(tableId, voidingLineId!)`, clear `voidingLineId`
    - ManagerPinModal `onOpenChange(false)`: clear `voidingLineId`

    Render ManagerPinModal inside TicketPanel:
    ```tsx
    <ManagerPinModal
      open={voidingLineId !== null}
      onOpenChange={(open) => { if (!open) setVoidingLineId(null) }}
      actionLabel="Authorize: Void Item"
      onAuthorize={() => {
        if (voidingLineId) useOrderStore.getState().voidItem(tableId, voidingLineId)
        setVoidingLineId(null)
      }}
    />
    ```

    **qty change handler in TicketPanel (passed to TicketLineItem):**
    ```typescript
    const handleQtyChange = (lineId: string, delta: number) => {
      const order = useOrderStore.getState().orders[tableId]
      if (!order) return
      for (const round of order.rounds) {
        const item = round.items.find(i => i.lineId === lineId)
        if (item && item.status === 'unsent') {
          const newQty = Math.max(1, item.quantity + delta)
          useOrderStore.getState().editItem(tableId, lineId, { ...item, quantity: newQty })
          return
        }
      }
    }
    ```
