  <name>Task 1: Install Sonner and create order.store.ts with full type model and Zustand actions</name>
  <files>src/stores/order.store.ts</files>
  <action>
    First, install sonner: `npm install sonner`

    Then create `src/stores/order.store.ts` following the exact Zustand 5 pattern from `src/stores/table.store.ts` (no persist middleware, `create<StoreType>()`, direct `set()` calls).

    Export these types: `LineItemStatus`, `ModifierSelection`, `OrderLineItem`, `OrderRound`, `ActiveOrder`.

    The store holds `orders: Record<string, ActiveOrder>` keyed by tableId.

    Implement these actions exactly:

    **addItem(tableId, item):** If no order exists for tableId, create one with a single unsent round containing the item. If an order exists, find the last round with `sentAt === null` using `findLastIndex`; if found, append item to that round's items array. If all rounds are sent, push a new round `{ roundId: crypto.randomUUID(), sentAt: null, items: [item] }`. Always immutable — spread all objects.

    **editItem(tableId, lineId, updated):** Find the round and item by lineId across all rounds; replace the item with `updated`. Use `Array.prototype.map` on rounds and items, replacing only the matching lineId.

    **removeItem(tableId, lineId):** Find the round containing the lineId; filter it out of that round's items. Only works on unsent items (status: 'unsent') — callers are responsible for not calling this on sent items.

    **sendRound(tableId):** Find all rounds where `sentAt === null`. For each such round, set `sentAt: Date.now()` and map all items with `status: 'unsent'` to `status: 'sent'`. Rounds that already have `sentAt !== null` are unchanged.

    **voidItem(tableId, lineId):** Find item by lineId across all rounds; set its `status: 'voided'`. Item remains in the list — do NOT remove it.

    **getOrder(tableId):** Return `state.orders[tableId]` (may be undefined for tables with no order yet).

    Add polyfill guard for crypto.randomUUID: `const newId = typeof crypto !== 'undefined' ? crypto.randomUUID() : Math.random().toString(36).slice(2)` — use this helper inline where UUIDs are needed.

    No `'use client'` directive on the store file itself (same pattern as table.store.ts).
  </action>
