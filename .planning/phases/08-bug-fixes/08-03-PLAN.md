Create a new file at src/components/app-shell/ThemedToaster.tsx.

This must be a `'use client'` component because it uses the `useTheme` hook. The (kds)/layout.tsx is a Server Component — importing useTheme directly there would cause a build error. This thin wrapper avoids converting the full layout.

```typescript
'use client'

import { Toaster } from 'sonner'
import { useTheme } from 'next-themes'

export function ThemedToaster() {
  const { resolvedTheme } = useTheme()
  return (
    <Toaster
      position="top-center"
      theme={resolvedTheme as 'light' | 'dark' | 'system'}
    />
  )
}
```

Use `resolvedTheme` (not `theme`) — `theme` can be the string 'system' which sonner does not handle correctly. `resolvedTheme` is always 'light' or 'dark'.

The component has no props and no state beyond the theme read.
