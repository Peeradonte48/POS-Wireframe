## Integration Gaps (Ranked by Impact)

### 1. Critical — TRACK-01, TRACK-03: KDS bump doesn't write orderStage to table.store

**File:** `src/components/kds/KdsTicketCard.tsx`

`bumpTicket()` advances `kds.store` only. `table.store.orderStage` is never written during the kitchen cycle — it stays at `'Ordered'` until payment sets it to `'Billed'`. The TableTile badge shows blue "Ordered" for the entire kitchen lifecycle.

**Fix:** Add `useTableStore.getState().updateTable()` calls in `KdsTicketCard.tsx`:
- `New → InProgress`: write `orderStage: 'Cooking'`
- `InProgress → Ready`: write `orderStage: 'Ready'`
- Ticket removal (Ready → off board): write `orderStage: 'Served'`

Note: `OrderTimeline` is unaffected — it calls `deriveRoundStage()` which reads `kds.store.tickets` directly.

### 2. Medium — SPLIT-03: onAllPaid path omits orderStage: 'Billed'

**File:** `src/app/(app)/payment/[tableId]/page.tsx` lines 311–315

The `onAllPaid` split callback calls `dissolveAll` and `markCleaning` for secondaries but never sets `orderStage: 'Billed'`. Table enters Cleaning with stale orderStage.

**Fix:** Add `useTableStore.getState().updateTable(tableId, { orderStage: 'Billed' })` to `onAllPaid`.

### 3. Low — MERGE-01: markClean doesn't call dissolveAll

**File:** `src/components/table-map/TableBottomSheet.tsx` lines 289–292

"Mark Clean" button calls `cancelSplit` + `markClean` but not `dissolveAll`. A merged primary that reaches Cleaning via this path (instead of payment) leaves the `merges` map dirty — secondary tiles show stale merge badge.

**Fix:** Add `useBillStore.getState().dissolveAll(table.id)` before `markClean`.
