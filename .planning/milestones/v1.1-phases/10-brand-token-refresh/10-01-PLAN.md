From src/app/globals.css (established 3-block token pattern):
```css
/* Block 1: @theme { } — literal static values, NOT dark-mode aware */
@theme {
  --color-brand-red: oklch(0.52 0.22 27);
}

/* Block 2: @theme inline { } — ONLY var() aliases, NEVER literal OKLCH here */
/* CRITICAL: Putting literal OKLCH in @theme inline silently breaks dark mode */
@theme inline {
  --color-primary: var(--primary);  /* ← correct pattern */
}

/* Block 3: :root { } — light mode literal values */
:root {
  --primary: oklch(0.52 0.22 27);
}

/* Block 4: .dark { } — dark mode overrides */
.dark {
  --primary: oklch(0.63 0.22 27);
}
```
