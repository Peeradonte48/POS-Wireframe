**Step 1 — Ensure 'use client' directive:**
manager/page.tsx must be a client component (needs hooks). If `'use client'` is not already at the top of the file, add it as the very first line.

**Step 2 — Add required imports (if not already present):**
```typescript
import { useEffect } from 'react'
import { useRouter } from 'next/navigation'
import { useSessionStore } from '@/stores/session.store'
```

If any of these imports already exist in the file, do not duplicate them.

**Step 3 — Add hook calls inside the component function:**
At the top of the ManagerPage component body (before any conditional returns or JSX), add:
```typescript
const router = useRouter()
const { role } = useSessionStore()
```

If `role` is already destructured from `useSessionStore`, do not add it again — just add the `router` hook.

**Step 4 — Add useEffect guard:**
```typescript
useEffect(() => {
  if (role !== null && role !== 'Manager') {
    router.replace('/table-map')
  }
}, [role, router])
```

Critical: The condition must be `role !== null && role !== 'Manager'`. Do NOT use `role !== 'Manager'` alone — that would trigger when role is null (before Zustand hydration), causing a redirect before the (app)/layout.tsx auth guard runs, producing an incorrect redirect destination or loop.

**Step 5 — Add early return to prevent content flash:**
After the useEffect, add:
```typescript
if (role !== 'Manager') return null
```

This prevents non-Manager users from seeing a flash of the manager page content before the useEffect redirect fires. It also covers the null case (unauthenticated users see blank while the layout redirects them to /login).

Place this early return AFTER the useEffect hook call (hooks must not be called conditionally), but BEFORE any JSX return statement.

Do not change any other logic, UI, or state in the file.
